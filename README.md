# Valéria Maria · Aulas de direção

Site da instrutora Valéria Maria (Betim, Belo Horizonte e Contagem).

- `site/` é o site publicado no Vercel (HTML estático, sem etapa de build).
- `autopainel/` guarda o projeto AutoPainel antigo (Vite + React). Para rodar: `cd autopainel && npm install && npm run dev`.
